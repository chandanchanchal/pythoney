# Hands-On Lab (HOL)

## AI for Developers -- Day 2

### Building an AI-Powered Client Onboarding Documentation Service

**Duration:** 4 Hours\
**Format:** Guided implementation lab\
**Goal:** Build a production-style Spring AI service that generates
onboarding documentation from a client profile.

Participants will implement the following endpoint:

`POST /api/onboarding/generate`

**Input →** Client Profile\
**Output →** AI-generated onboarding documentation (JSON)

------------------------------------------------------------------------

# Lab Overview

  Lab     Topic                                       Duration
  ------- ------------------------------------------- ----------
  Lab 1   Spring AI Project Setup                     30 min
  Lab 2   First AI Call Using ChatClient              30 min
  Lab 3   PromptTemplate with Variables               45 min
  Lab 4   Structured JSON Output                      45 min
  Lab 5   Build Client Onboarding Service             60 min
  Lab 6   Validation, Error Handling & Improvements   30 min

**Total Duration:** 4 hours

------------------------------------------------------------------------

# Lab 1 --- Spring AI Project Setup

**Duration:** 30 minutes

## Objective

Create a Spring Boot project and configure Spring AI with an LLM
provider.

## Tasks

### Task 1 --- Create Spring Boot Project

Create a new project using **Spring Initializr**.

Required dependencies:

-   Spring Web
-   Spring Boot DevTools
-   Lombok
-   Spring AI OpenAI Starter

Project name:

`spring-ai-onboarding-service`

------------------------------------------------------------------------

### Task 2 --- Configure Application Properties

Add configuration for:

-   API key
-   Model
-   Temperature
-   Max tokens

Participants should:

-   Store API key using environment variables
-   Configure model options in `application.properties`

------------------------------------------------------------------------

### Task 3 --- Verify Bean Creation

Confirm Spring AI auto-configuration creates required beans.

Participants should:

-   Check logs
-   Identify `ChatModel` and `ChatClient` beans

------------------------------------------------------------------------

# Lab 2 --- First AI Call Using ChatClient

**Duration:** 30 minutes

## Objective

Make the first AI request from a Spring service.

## Tasks

### Task 1 --- Create Service Class

Create a service:

`AiTestService`

Inject:

`ChatClient.Builder`

Build a ChatClient instance.

------------------------------------------------------------------------

### Task 2 --- Send a Simple Prompt

Create a method:

`String askAI(String question)`

Send a prompt asking the model to:

`Explain what KYC compliance means in banking.`

------------------------------------------------------------------------

### Task 3 --- Create a REST Endpoint

Expose an endpoint:

`GET /api/ai/ask?q=...`

Return the model response.

------------------------------------------------------------------------

### Task 4 --- Test the Endpoint

Use:

-   Postman
-   curl
-   browser

Verify the response is generated by the LLM.

------------------------------------------------------------------------

# Lab 3 --- PromptTemplate with Variables

**Duration:** 45 minutes

## Objective

Implement dynamic prompt generation using PromptTemplate.

## Scenario

The system will generate a **client onboarding summary**.

------------------------------------------------------------------------

### Task 1 --- Create ClientProfile Model

Create a class representing client input.

Fields:

-   clientName
-   industry
-   services
-   region
-   tier

------------------------------------------------------------------------

### Task 2 --- Create PromptTemplate

Create a prompt template with variables for:

-   client_name
-   industry
-   services
-   region

The prompt should instruct the model to generate a **professional
onboarding summary**.

------------------------------------------------------------------------

### Task 3 --- Map Variables

Create a `Map` of variables from the `ClientProfile` object.

Inject these variables into the template.

------------------------------------------------------------------------

### Task 4 --- Generate Prompt

Use `PromptTemplate` to produce a `Prompt` instance.

Send the prompt using `ChatClient`.

Return the generated summary.

------------------------------------------------------------------------

# Lab 4 --- Structured JSON Output

**Duration:** 45 minutes

## Objective

Force the model to return structured JSON.

## Target Output

``` json
{
 "summary": "...",
 "next_steps": [],
 "risk_flags": []
}
```

## Tasks

### Task 1 --- Update Prompt Instructions

Modify the prompt to require:

`Return ONLY valid JSON`

Define the JSON schema inside the prompt.

------------------------------------------------------------------------

### Task 2 --- Parse AI Response

Use **Jackson ObjectMapper** to convert the response into:

`OnboardingDocumentResponse`

------------------------------------------------------------------------

### Task 3 --- Handle Parsing Errors

Implement logic to detect:

-   invalid JSON
-   missing fields

Log malformed responses.

------------------------------------------------------------------------

### Task 4 --- Improve Prompt Reliability

Participants should experiment with:

-   adding constraints
-   clarifying output format
-   reducing hallucinations

------------------------------------------------------------------------

# Lab 5 --- Build Client Onboarding Service

**Duration:** 60 minutes

## Objective

Build the real service endpoint.

## Tasks

### Task 1 --- Create Service Layer

Create:

`OnboardingService`

Responsibilities:

-   accept client profile
-   generate prompt
-   call ChatClient
-   return structured output

------------------------------------------------------------------------

### Task 2 --- Implement PromptTemplate

Create a reusable prompt template for onboarding documentation.

Include instructions for:

-   summary
-   next steps
-   risk flags

------------------------------------------------------------------------

### Task 3 --- Create REST Controller

Endpoint:

`POST /api/onboarding/generate`

Input:

`ClientProfile`

Output:

`OnboardingDocumentResponse`

------------------------------------------------------------------------

### Task 4 --- Test with Multiple Clients

Participants should test using different inputs such as:

-   Trade Finance company
-   Retail Banking client
-   Corporate client

Observe how prompt context changes results.

------------------------------------------------------------------------

# Lab 6 --- Validation, Error Handling & Improvements

### Task 3 --- Add Logging

-   max tokens

via properties.
